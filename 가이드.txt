====================================================================
 MAKE IT REAL — 메이킹 수업 포트폴리오 웹페이지 가이드
====================================================================

이 파일은 index.html 포트폴리오 페이지를 학생 개인의 내용으로
바꿔 넣는 방법을 설명합니다. 코딩을 몰라도 메모장/VS Code로
텍스트만 바꾸면 완성할 수 있도록 만들었습니다.


1. 폴더 구조
--------------------------------------------------------------------
    portfolio/
    ├── index.html      ← 웹페이지 본체 (이 파일만 열면 바로 실행됨)
    ├── 가이드.txt       ← 지금 보고 있는 안내 파일
    └── images/          ← 사진을 넣는 폴더 (아래 2번 참고)

index.html를 더블클릭하면 크롬/엣지 같은 브라우저에서 바로
열립니다. 별도 서버나 프로그램 설치가 필요 없습니다.


2. 사진 넣는 방법 (가장 중요!)
--------------------------------------------------------------------
images 폴더 안에 아래 "정확한 파일 이름"으로 사진을 넣어주세요.
이름을 다르게 저장하면 사진이 보이지 않고, 대신 점선 격자무늬의
"이미지 대기중" 안내가 자동으로 표시됩니다. (깨진 이미지 아이콘이
아니라 디자인된 placeholder라 사진 없이 제출해도 어색하지 않아요.)

  images/hero-character.jpg   대표 캐릭터 사진 (맨 위 히어로 영역)
                               권장 비율 4:5 (예: 1000×1250px)

  images/work-01.jpg  ~  work-06.jpg
                               갤러리 카드 6개용 사진
                               권장 비율 1:1 정사각형 (예: 1200×1200px)
                               → 카드 개수를 늘리거나 줄이고 싶다면
                                 3번 항목 참고

  images/profile.jpg          자기소개(About) 영역의 프로필 사진
                               권장 비율 3:4 (예: 900×1200px)

사진 촬영 팁
  - 배경은 되도록 흰색/무채색 단색 종이 위에서 촬영하면
    도면(블루프린트) 느낌의 디자인과 잘 어울립니다.
  - 정면 + 측면 등 여러 각도 중 결과물이 가장 잘 보이는 한 장을
    고르세요.
  - 파일 용량이 큰 경우(5MB 이상) 웹에서 느리게 열릴 수 있으니
    적당히 압축해서 넣는 것을 추천합니다.


3. 텍스트 수정하는 방법
--------------------------------------------------------------------
index.html을 메모장, VS Code, Sublime Text 등으로 "열기"
(더블클릭이 아니라 마우스 우클릭 → 연결 프로그램)한 뒤,
아래처럼 대괄호 [ ] 로 표시된 부분을 자신의 내용으로 바꿔주세요.
대괄호 표시는 안내용이므로 대괄호까지 전부 지우고 실제 내용만
입력하면 됩니다.

  찾아 바꾸면 되는 대표 위치
  ────────────────────────────────────────────
  [이름]              → 본인 이름 (여러 곳에 반복 등장)
  [학과 / 학번]        → 소속 학과, 학번
  [캐릭터 이름]         → 대표 캐릭터의 이름
  [작품명]             → 갤러리 카드마다 다른 작품 이름
  [학교명]             → 소속 학교 이름
  자기소개 문단          → about-copy 영역의 안내 문구를 지우고
                        본인 이야기로 채우기

  갤러리 카드 하나의 구조 (JOB #01 카드를 예로)
  ────────────────────────────────────────────
    <span class="card-id">JOB #01</span>   ← 작업 번호 (그대로 둬도 OK)
    <span class="card-tags">FIGURE</span>  ← 카테고리 (FIGURE / KEYRING / PUZZLE / GOODS / BADGE 등)
    <h3>[작품명] 피규어</h3>                 ← 작품 제목
    <p class="desc">...</p>                ← 한두 문장 설명
    <div class="spec"> ... </div>          ← 공정 / 재료 / 사이즈 / 제작시간

  갤러리 카드를 늘리거나 줄이려면
  ────────────────────────────────────────────
  index.html에서 <!-- CARD 0n --> 주석부터 </article> 태그까지가
  카드 하나의 단위입니다. 이 블록 전체를 복사해서 붙여넣으면
  카드가 추가되고, 블록을 지우면 카드가 줄어듭니다.
  카드를 추가/삭제했다면 상단 "완료된 제작물 06" 숫자와
  이미지 파일명(work-07.jpg 등)도 함께 맞춰주세요.

  연락처 링크 수정
  ────────────────────────────────────────────
  하단 About 영역의 아래 부분에서 실제 이메일/SNS 주소로
  바꿔주세요.
    <a href="mailto:example@email.com" class="btn">Email</a>
    <a href="#" class="btn">Instagram</a>   ← href="#" 를 실제 링크로 교체
    <a href="#" class="btn">Behance</a>


4. 디자인 콘셉트 설명 (선택 사항으로 읽어보기)
--------------------------------------------------------------------
이 템플릿은 "설계 도면(블루프린트) + 제작 작업지시서" 컨셉을,
밝은 베이지 톤의 미니멀한 톤으로 다듬은 버전입니다.
  - 연한 베이지 배경과 옅은 격자무늬: 3D 모델링/레이저 커팅
    도면 화면을 은은하게 표현
  - 흰색 카드 + 모서리 십자(+) 표시: 레이저 커팅 파일의 정렬
    기준점을 사진 카드에 재현
  - JOB #01, #02… 번호: 실제 제작 순서를 기록하는 작업 번호
  - 카드 하단 공정/재료/사이즈/제작시간: 3D프린터·레이저커터의
    출력 사양표를 그대로 옮긴 표기
  - 히어로 영역의 진행 바(progress bar): 3D프린터 출력 진행률 화면
포인트 컬러(더스티 로즈)는 버튼, 작업 번호, 진행 바 등
"눈에 띄어야 하는 곳"에만 절제해서 사용했고, 나머지는 모두
베이지·화이트·그레이 톤으로 차분하게 정리했습니다.


5. 색상만 바꾸고 싶다면
--------------------------------------------------------------------
index.html 상단 <style> 안, ":root { ... }" 부분의 값만 바꾸면
전체 페이지 색이 함께 바뀝니다.

  --bg      : 배경색 (기본: 밝은 베이지 #F8F5EF)
  --accent  : 포인트색 / 버튼색 (기본: 더스티 로즈 #A85D68)
  --paper   : 카드(사진 박스) 배경색 (기본: 화이트)
  --ink     : 본문 텍스트 색 (기본: 다크 브라운 그레이)
  --muted   : 보조 텍스트, 라벨 색 (기본: 웜 그레이)

예: --accent 값을 #A85D68 에서 원하는 색상 코드로 바꾸면
    버튼, 작업 번호, 진행 바 색이 한 번에 바뀝니다.
    (세이지 그린 #6B8F71, 라벤더 #8E7CC3 등으로 바꿔도 잘 어울립니다.)


6. 완성 후 제출/공유 방법
--------------------------------------------------------------------
  - portfolio 폴더 전체(index.html + images 폴더)를 압축(zip)해서
    제출하면 됩니다. index.html만 따로 제출하면 사진이 표시되지
    않으니 반드시 images 폴더와 함께 제출/보관하세요.
  - 온라인에 공개하고 싶다면 GitHub Pages, Netlify 같은 무료
    호스팅 서비스에 폴더를 그대로 올리면 별도 서버 설정 없이
    바로 웹사이트로 볼 수 있습니다.


궁금한 점이 있으면 클로드에게 "index.html에서 ○○ 부분을
△△로 바꿔줘"처럼 자연어로 요청해도 수정할 수 있어요.
