[AI 툴 활용] 나만의 메이킹 포트폴리오 커스텀 프롬프트 가이드
==================================================================

1. 개요
본 수업에서 제공된 기본 index.html 과 styles.css 를 바탕으로 
각자 생성형 AI에 질문하여 나만의 웹사이트로 변형/개선할 수 있습니다.

------------------------------------------------------------------
2. AI(Claude / ChatGPT / Gemini) 활용 프롬프트 예시
------------------------------------------------------------------

[기본 텍스트 및 내용 교체 요청]
"내가 만든 메이킹 작품 3개(3D 프린팅 인형, 레이저 커팅 아크릴 키링, 우드 퍼즐)에 대한 
소개 글을 작성해줘. 나의 이름은 [이름]이고 컨셉은 [모던/귀여운/키치한] 느낌이야. 
index.html 파일 안에 바로 넣을 수 있게 카드 형태의 HTML 태그로 제공해줘."

[디자인 색상 및 분위기 변경 (styles.css 수정)]
"제공된 styles.css 코드에서 배경색을 다크 모드(Dark Mode) 스타일로 바꾸고 싶어. 
메인 색상은 스카이 블루 대신 '포인트 오렌지' 컬러를 쓰고 싶어. 수정해야 할 CSS 부분을 짚어서 전체 코드를 다시 작성해줘."

[기능 추가 요청 (레이아웃 변형)]
"갤러리 카드에 마우스를 올렸을 때(Hover effect) 이미지가 살짝 확대되면서 
작품 설명이 위로 올라오는 애니메이션 효과를 추가하고 싶어. CSS 코드 작성해줘."

------------------------------------------------------------------
3. 파일 및 이미지 경로 준비 체크리스트
------------------------------------------------------------------
[ ] index.html 파일과 동일한 위치에 'image' 폴더가 있는지 확인
[ ] image 폴더 내 이미지 파일명이 정확한지 확인
    - profile.jpg (본인 프로필/캐릭터)
    - item1.jpg   (3D 프린터 작품)
    - item2.jpg   (레이저 커팅 키링)
    - item3.jpg   (레이저 커팅 퍼즐)
[ ] 이미지 확장자(.jpg, .png)가 코드와 일치하는지 확인
