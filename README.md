# 자료실 포털 — 사용 안내

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 교육자에게 공개할 페이지. 로그인 + 메뉴 + 자료 보기 |
| `data.enc.js` | 암호화된 메뉴·링크 데이터. 이것만 교체하면 메뉴가 바뀜 |
| `builder.html` | 메뉴를 편집해 `data.enc.js`를 만드는 도구. **공개 서버에 올리지 말 것** |

세 파일 중 `index.html`과 `data.enc.js` 두 개만 같은 폴더에 올리면 됩니다.

## 첫 접속
- 아이디 `admin` / 비밀번호 `edu2026!`
- **반드시 `builder.html`로 새 비밀번호를 정해 `data.enc.js`를 다시 만든 뒤 배포하세요.**

## 메뉴 수정 방법
1. `builder.html`을 브라우저로 엽니다(더블클릭).
2. 기존 아이디·비밀번호를 입력하고 `기존 파일 불러와 수정` → 현재 `data.enc.js` 선택.
3. 메뉴 이름과 주소를 고칩니다. 분류·메뉴는 개수 제한 없이 추가/삭제 가능합니다.
4. `data.enc.js 내려받기` → 서버의 기존 파일을 덮어씁니다.

비밀번호를 바꾸려면 3번에서 새 비밀번호를 넣고 다시 내려받으면 됩니다.

## 암호화 방식
- 비밀번호는 **어디에도 저장되지 않습니다.** `아이디 + 비밀번호`에서 PBKDF2-SHA256(25만 회)로 키를 만들고, 그 키로 AES-GCM 256 암호문을 풀어야만 메뉴가 나타납니다.
- `if (pw === "....")` 같은 비교문이 없으므로, 코드를 고쳐서 통과하는 방식이 성립하지 않습니다.
- 링크 주소는 DOM에 남지 않습니다. 버튼에는 좌표(`0.3`)만 있고, 주소는 클릭하는 순간 메모리에서 꺼내 씁니다.
- 자료는 페이지 안 프레임에서 열리므로 주소창에 경로가 드러나지 않습니다.
- 새로고침하면 복호화된 데이터가 사라져 다시 로그인해야 합니다(브라우저 저장소를 쓰지 않음).

## 알아 두셔야 할 한계
- **로그인한 사람은 개발자 도구로 링크를 볼 수 있습니다.** 브라우저가 화면에 띄우려면 결국 메모리에 주소가 있어야 하기 때문입니다. 이건 어떤 방식으로도 막을 수 없습니다. 이 구조가 막아 주는 것은 *비밀번호를 모르는 사람*입니다.
- 비밀번호를 아는 교육자가 링크를 외부에 유출하는 것은 기술로 막을 수 없습니다. 링크 자체의 접근 제어(구글 드라이브 공유 설정 등)를 함께 쓰세요.
- 프레임 안에서 안 열리는 사이트가 있습니다(구글, 네이버 등은 프레임 표시를 차단). 이때는 `새 탭에서 열기`를 쓰면 됩니다.
- 아이디·비밀번호를 잊으면 `data.enc.js`는 복구할 수 없습니다. 메뉴 목록은 따로 보관해 두세요.

## 보안을 더 올리려면
- HTTPS로 서비스하세요.
- 비밀번호는 12자 이상, 학교·연도 조합처럼 추측 가능한 형태는 피하세요.
- 정말로 링크를 통제해야 한다면 서버에서 세션을 검증하고 주소를 내려주는 방식(백엔드)이 필요합니다. 현재 구조는 서버 없이 가능한 최대치입니다.
